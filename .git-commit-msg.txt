Fix two bugs + improve conviction-mapping realism

Bug A (map -> wrong states):
The U.S. coverage map links to /jobs?region=MN, but /jobs/page.tsx
read filters only from text inputs and ignored the URL query string.
Every state click landed unfiltered, showing jobs from all states.

Fix: useSearchParams() to seed the location text field (and other
filters) on first paint. parseLocationInput() already understands a
2-letter state code, so seeding locationInput=MN produces the
right region filter automatically. Also seeds q, industry,
offenseType, and apprenticeshipsOnly.

Bug B (conviction-mapping realism):
Generic words like "school", "minors", "students" were tripping
high-concern rules in non-workplace contexts. Worst offender:
"high school diploma required" capped any job at score 44 for
registry-related and violent-offense convictions because the
hard-barrier school_setting pattern matched "high school".

Fixes in risk-matrix.ts:
- ConcernRule now supports surface=company / title / company_or_title
  for high-confidence workplace markers
- New notKeywords veto list per rule
- evaluateMatrix honors both
- Registry-related and violent-offense matrices reworked: workplace
  markers on company/title only, role markers on title only

Fixes in signals.ts:
- school_setting no longer matches generic "high school".
  Requires workplace context (school district / setting / campus /
  grounds / facility / building / board) or unambiguous workplace
  words (kindergarten, preschool, daycare, k-12).
- children_or_minors requires a workplace verb (work with / around
  / supervise / care for / tutor / teach) so "minor injuries" and
  "may receive student loan" no longer fire.

Tests: 26/26 pass, +3 regression cases (school-diploma noise on
warehouse jobs, plus a positive control on Renton School District).
